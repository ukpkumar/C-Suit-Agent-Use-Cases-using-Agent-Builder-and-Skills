# 3) Build Steps for Any Agent

Follow this sequence for each agent:

1. Open Microsoft 365 Copilot or Teams, go to **Agents & Skills**, select **New agent**.
2. On **Describe**, paste the agent build prompt.
3. Open **Configure**, validate name and description.
4. Replace generated instructions with the full instructions for the scenario.
5. Set model response mode (Auto / Quick response / Think deeper).
6. Add required knowledge sources (email, Teams, SharePoint, websites, files, list, connectors).
7. Enable capabilities (code interpreter, image generation, web search as needed).
8. Add skills (upload `.zip` or generate from Describe prompt).
9. Add starter prompts.
10. Set icon.
11. Run all starter prompts and test checklist on **Try it**.
12. Create and share agent with target users or security group.
