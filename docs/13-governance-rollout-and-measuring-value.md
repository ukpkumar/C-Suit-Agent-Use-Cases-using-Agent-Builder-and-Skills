# 13) Governance, Rollout, and Measuring Value

## 13.1 Governance

- Assign an owner per agent and quarterly review date.
- Share to least-privilege audiences (exec + support team/security group).
- Validate permissions/sensitivity labels for every source.
- Keep web search off/scoped for confidential workflows (Board/CFO/CRO).
- Monitor inventory/usage in Microsoft 365 admin center and auditing in Purview.
- Keep HR guardrails intact (no individual evaluation/profiling; minimum group size).

## 13.2 Suggested rollout

| Phase | Weeks | Activities |
|---|---|---|
| Prepare | 1-2 | Confirm licensing/settings, prep data sources, define pilot measures |
| Build | 2-3 | Build agents, add skills, run test checklists |
| Pilot | 4-7 | Daily usage, weekly feedback, refine instructions/skills |
| Scale | 8+ | Extend to leadership teams; move action/scheduled flows to Copilot Studio |

## 13.3 Value measures

| Measure | How to capture |
|---|---|
| Time saved per executive/week | Weekly pulse survey |
| Pack preparation effort | Before/after hours comparison |
| Agent usage | Admin center usage analytics |
| Quality/trust | % of answers accepted without correction |
| Report turnaround | Days to produce recurring outputs |
