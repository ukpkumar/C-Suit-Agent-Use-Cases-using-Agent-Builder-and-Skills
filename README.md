# Executive and C-Suite Agents with Agent Builder and Skills

This repository provides a practical build guide for creating executive-ready agents in **Microsoft 365 Copilot Agent Builder**, with reusable **skills** and governance guardrails.

It is designed for leaders and their support teams (Chief of Staff, EA, analysts) who need repeatable agent patterns for decision support, reporting, and meeting preparation.

## What this repository contains

- Eight ready-to-build executive agent use cases:
  - CEO Daily Brief
  - Board Pack Navigator
  - CFO Performance Analyst
  - Operations Control Tower
  - People and Culture Advisor
  - Tech and AI Portfolio Advisor
  - Market Intelligence Advisor
  - Regulatory and Risk Radar
- Build prompts for the **Describe** tab
- Full instruction sets for the **Configure** tab
- Recommended knowledge sources, capabilities, and skills
- Starter prompts and test checklists
- Rollout, governance, and value-measurement guidance

## Who should use this

- Executive offices and C-suite support teams
- Strategy, finance, operations, HR, risk, and technology leadership teams
- Copilot adoption and governance leads

## Outcome

Use this content to stand up high-value executive agents quickly, with clear boundaries on data use, quality, and responsible AI behavior.
